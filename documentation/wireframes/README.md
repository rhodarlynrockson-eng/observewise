# ObserveWise Wireframes

These wireframes were created in Canva to plan the layout, navigation and content before development of observewise.

## Completed wireframes

- Home page — desktop
- Home page — mobile
- Observation prototype — desktop
- Observation prototype — mobile

The desktop and mobile layouts show how the content will adapt to different screen sizes. The prototype includes structured observation fields, the child's voice, areas of development, learning and next steps, with a reminder to use fictional information.

## Design decisions

### Why Canva was used

Canva was chosen because its drag-and-drop tools allowed the arrangement of the navigation, content and form fields while developing  the design skills. Duplicating elements helped maintain consistency between layouts while Exporting the designs as PNG files makes them easy to include in the project documentation.

### Why four wireframes were created

Four wireframes cover the Home page and observation prototype, each at desktop and mobile sizes. The Home page introduces ObserveWise and directs users towards its resources. The prototype represents the main observation-writing activity and contains the most detailed form.

These two pages were selected to plan both the introductory experience and the main task. Desktop and mobile versions explore how navigation, spacing and content adapt to different screen widths.

The Observation Guide, Student Hub and 404 page will follow the shared design patterns established here. Their layouts will be checked during development through responsive and usability testing.
